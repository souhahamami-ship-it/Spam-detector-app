# 📧 Spam Email Detector

A Flask web app that detects whether an email is Spam or Ham using Machine Learning.

## 🚀 Features
- Text preprocessing (NLTK)
- ML model prediction
- Simple web interface

## 🛠️ Tech Stack
- Python
- Flask
- TensorFlow
- Scikit-learn

## ▶️ Run locally

```bash
pip install -r requirements.txt
python app.py
